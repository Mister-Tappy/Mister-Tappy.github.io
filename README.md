### 🧭 University Hub Setup

The project now includes a dynamic University Hub page built with JSON-driven data, vanilla JavaScript modules, and a glassmorphism dark UI.

#### Files added
- university-hub.html
- university-hub.css
- js/university.js
- js/search.js
- js/favorites.js
- data/universities.json
- data/announcements.json
- assets/universities/

#### Run locally
1. Open the project folder in a local web server.
2. From the workspace root, run:
   python3 -m http.server 8000
3. Then visit:
   http://localhost:8000/university-hub.html

#### Notes
- Favorites are stored in localStorage.
- Search, filters, countdowns, and modals are all client-side.
- Additional universities can be added by extending the JSON files and assets folder.
